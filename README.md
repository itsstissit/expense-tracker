# 💰 Expense Tracker

A full stack expense tracking web application.

## Tech Stack
- **Backend:** Java, Spring Boot, REST API
- **Frontend:** HTML, CSS, JavaScript
- **Database:** MySQL

## Features
- Add and delete expenses
- Categorize expenses (Food, Transport, Shopping, Bills)
- Automatic total calculation
- Data persists in MySQL database

## How to Run
1. Set up MySQL and create the `expense_tracker` database
2. Update `application.properties` with your MySQL password
3. Run the Spring Boot backend in IntelliJ
4. Open `index.html` in your browser
